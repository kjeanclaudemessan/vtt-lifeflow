This directory contains Rive (.riv) animation files.

Files are created at https://rive.app and exported as .riv binaries.

Convention:
- onboarding_habits.riv   → Slide 1 (habits illustration)
- onboarding_time.riv     → Slide 2 (time illustration)
- onboarding_progress.riv → Slide 3 (progress illustration)

State machine naming: use "idle" as the default state machine name.
