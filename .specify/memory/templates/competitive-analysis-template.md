# Competitive Analysis Template

> **Prérequis** : le Business Model est rédigé.
> Ce template analyse la concurrence en profondeur — pas une liste de features, mais une compréhension de POURQUOI les gens utilisent (ou quittent) chaque concurrent.
> L'IA fait les recherches. Le créateur valide les insights.

---

## 🤖 INSTRUCTIONS IA

1. Lis le BM (sections 2, 7, 8 en priorité)
2. Identifie **5 à 8 concurrents** réels — pas juste les directs, aussi les indirects et les substituts
3. Pour chaque concurrent : va au-delà de la fiche technique. Analyse les AVIS utilisateurs (App Store, Play Store, Reddit, Twitter) pour comprendre ce que les gens AIMENT et DÉTESTENT
4. Identifie le "job to be done" que chaque concurrent adresse — et les jobs qu'il néglige
5. Trouve le TROU — l'espace que personne n'occupe et que notre produit peut prendre

## Cartographie du marché

### Les 3 cercles de concurrence

> **IA** : Classe les concurrents en 3 cercles.

#### Cercle 1 — Concurrents directs

> Font exactement ce que nous faisons (même problème, même cible).

#### Cercle 2 — Concurrents indirects

> Résolvent le même problème mais avec une approche différente (ex: un coach humain, un livre, une méthode papier).

#### Cercle 3 — Substituts

> Ce que les gens font À LA PLACE d'utiliser une solution (ex: rien, ils acceptent le problème / ils bricolent avec Notes + Calendar + Rappels).
