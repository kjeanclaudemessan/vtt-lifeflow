# Changelog

All notable changes to LifeFlow will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Phase 1 — Daily Foundations: Domains, Habits, Routines, Tasks, Inbox
- Supabase integration with local development setup
- 7 database migrations (profiles, payments, domains, habits, routines, tasks, inbox_items)
- Stacked MVVM architecture with GetIt DI
- 46 integration tests covering all Phase 1 features
- CI/CD pipeline with GitHub Actions, Fastlane, Fly.io
- Design system foundation (AppColors, AppSpacing, AppTextStyles)

## [0.1.0] - 2025-01-22

### Added
- Initial project setup from VTT template
- Flutter app scaffold with Stacked architecture
- FastAPI backend scaffold
- Supabase configuration with local development
- Auth module (login, register, forgot password)
- Profile module
- Splash & onboarding screens
- Settings module
- Notifications module
